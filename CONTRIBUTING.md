# Contributing

Thank you for helping MissionCompiler become safer and easier to understand.

## Best contributions during the public preview

- A real coding task that was hard to route or approve.
- A case where the proposed risk, mode, capability, permission, or workspace choice is wrong.
- A usability issue that forces a non-technical user to understand Agent jargon.
- A minimal reproducible bug in the native app or policy engine.
- An anonymized evaluation case with expected policy output.

## License gate

The repository does not yet have an open-source license. Please open an Issue before submitting code. Code pull requests will remain closed until the contribution license is explicit for both maintainers and contributors.

Documentation corrections and reproducible Issue reports are welcome now.

## Issue quality

Include:

1. The raw mission.
2. Any non-negotiable constraint.
3. The expected mode, risk, permissions, and approval boundary.
4. What MissionCompiler proposed instead.
5. A sanitized environment description.

Never include secrets, private source code, credentials, personal data, or private contact information.
