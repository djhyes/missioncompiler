# License status

MissionCompiler is publicly visible but does not currently include an open-source license.

Until a license is added, default copyright rules apply. Viewing the repository does not by itself grant permission to reproduce, distribute, or create derivative works. This follows GitHub's explanation of [licensing a repository](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

The maintainer intends to choose a license after deciding the project's contribution and commercialization model. Likely options to evaluate are:

- MIT for maximum simplicity and permissive reuse.
- Apache-2.0 for permissive reuse with an explicit patent grant.
- A source-available model if commercial redistribution needs tighter control.

This file is a project-status notice, not legal advice.
